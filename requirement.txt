STEP 3 – Family Creation & Joining Flow
3.1 Create Family (Keeper)

Flow:

“Create Family” button

Enter family name

API → POST /families

Assign:

owner_id = user.id

role = keeper

family_id = created_family.id

3.2 Join Family (Member)

Flow:

Enter Family Code / Invite Link

API → POST /families/join

Assign:

family_id

role = member

STEP 4 – Role System (Keeper vs Member)
4.1 Role Rules
Feature	Keeper	Member
Create family	✅	❌
Invite members	✅	❌
Add recipe	✅	✅
Edit own recipe	✅	✅
Delete own recipe	✅	✅
Delete others’ recipes	✅	❌
Remove members	✅	❌
STEP 5 – Family Scoped Recipe Access Enforcement
5.1 API Layer

Every recipe API must include:

family_id == user.family_id


Blocked if:

user has no family

recipe belongs to another family

5.2 Flutter Guards

If user.family_id == null → show “Join or Create Family” screen

Home feed only loads:

GET /recipes?family_id=user.family_id
